# The Eras Tour of Computer Vision

A two-hour, hands-on workshop through three eras of computer vision — hand-crafted rules,
pretrained neural networks, and vision-language models — applied to the same set of 50 photos.

**[View the full workshop page &rarr;](https://linonu.github.io/eras-tour-workshop/)**

## Quick links

| Era | Notebook |
|---|---|
| Era 1: The Rules Era | [Open in Colab](https://colab.research.google.com/github/LinoNU/eras-tour-workshop/blob/main/part1_rules_workshop.ipynb) |

## What's in this repo

- `part1_rules_workshop.ipynb` — classical CV, two numbers to tweak
- `part2_classifier_workshop.ipynb` — pretrained classifier, one keyword setting to tweak
- `part3_vlm_activity.md` — a 5-image activity for any free chat assistant with image upload
- `data/` — the full 50-photo image set (mugs, near-miss distractors, true negatives) with
  ground truth labels, released under CC BY 4.0 (see `data/LICENSE.txt`)
