HSV Color Explorer

OpenCV's actual scale — not the 0–360° scale most color pickers use.

Most online HSV pickers use Hue 0–360° and Saturation/Value as percentages. OpenCV (and Era 1's color_mask()) uses a different scale: Hue 0–179, Saturation 0–255, Value 0–255. Drag the sliders below to see exactly what a given HSV triple looks like — and whether Era 1's actual code would flag it as a candidate mug color.

Era 1's actual ranges (from color_mask()):
white/light  →  H: 0–179, S: 0–60,  V: 150–255
blue-ish     →  H: 95–130, S: 80–255, V: 60–255

Try setting Hue to 95, then 130 — both pass, since they're the inclusive edges of the blue-ish range. Then try 94 or 131: same color family to the eye, but the code says no. That cliff-edge behavior at an arbitrary number is exactly why classical rules break the way they do.
